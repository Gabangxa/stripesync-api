API Reference

StripeSync API — version 1.0.0. Base URL: https://your-app.replit.app

Authentication

Pass your API key as Authorization: Bearer <your_api_key> on all requests except POST /v1/stripe/events/:workspace_id — Stripe calls that endpoint directly using Stripe's own signature header.

curl -H "Authorization: Bearer sk_live_yourkey" \
  https://your-app.replit.app/v1/workspaces

Workspaces

POST /v1/workspaces

Create a new workspace. Returns a generated webhook URL to paste into Stripe Dashboard.

Request Body

{
  "name": "My SaaS",
  "accounting_platform": "quickbooks",
  "stripe_webhook_secret": "whsec_live_...",
  "accounting_token": "Bearer ya29.live..."
}

Response 201

{
  "workspace_id": "ws_a1b2c3d4e5f6",
  "webhook_url": "https://your-app.replit.app/v1/stripe/events/ws_a1b2c3d4e5f6",
  "status": "active",
  "created_at": "2026-03-26T10:42:00Z"
}

curl

curl -X POST https://your-app.replit.app/v1/workspaces \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your_api_key" \
  -d '{
    "name": "My SaaS",
    "accounting_platform": "quickbooks",
    "stripe_webhook_secret": "whsec_live_...",
    "accounting_token": "Bearer ya29.live..."
  }'
GET /v1/workspaces/:id/webhook-url

Retrieve the generated Stripe webhook URL for an existing workspace.

Response 200

{
  "workspace_id": "ws_a1b2c3d4e5f6",
  "webhook_url": "https://your-app.replit.app/v1/stripe/events/ws_a1b2c3d4e5f6",
  "status": "active"
}

curl

curl https://your-app.replit.app/v1/workspaces/ws_a1b2c3d4e5f6/webhook-url \
  -H "Authorization: Bearer your_api_key"

Stripe Webhook Receiver

POST /v1/stripe/events/:workspace_id

This endpoint is called directly by Stripe — do not call it manually. Validates Stripe signature, maps event type to accounting action, and logs the result. No Authorization header required — Stripe authenticates via Stripe-Signature header.

Stripe sends (example)

{
  "id": "evt_3abc...",
  "type": "payment_intent.succeeded",
  "data": {
    "object": {
      "id": "pi_3abc...",
      "amount": 4900,
      "currency": "usd"
    }
  }
}

Response 200

{
  "received": true,
  "event_id": "evt_local_abc123",
  "accounting_action": "create_invoice_and_payment"
}

Events

GET /v1/events

Returns a paginated list of processed Stripe events from the in-memory log.

Query Parameters

ParamTypeDescription
workspace_idstringFilter by workspace
statusstringsuccess | failed | pending
limitintegerMax results (default: 20, max: 100)
offsetintegerPagination offset (default: 0)

Response 200

{
  "events": [
    {
      "event_id": "evt_001",
      "workspace_id": "ws_demo_alpha",
      "stripe_event_type": "payment_intent.succeeded",
      "stripe_event_id": "pi_3Oa1bcStripe001",
      "accounting_action": "create_invoice_and_payment",
      "accounting_platform": "quickbooks",
      "status": "success",
      "amount_cents": 4900,
      "currency": "usd",
      "created_at": "2026-03-25T08:12:00Z",
      "processed_at": "2026-03-25T08:12:01Z"
    }
  ],
  "total": 8,
  "limit": 20,
  "offset": 0
}

curl

curl "https://your-app.replit.app/v1/events?workspace_id=ws_abc&status=success&limit=10" \
  -H "Authorization: Bearer your_api_key"
POST /v1/events/:event_id/retry

Re-process a failed event. Only events with status: "failed" can be retried.

Response 200

{
  "event_id": "evt_004",
  "status": "success",
  "processed_at": "2026-03-26T12:00:00Z"
}

curl

curl -X POST https://your-app.replit.app/v1/events/evt_004/retry \
  -H "Authorization: Bearer your_api_key"
